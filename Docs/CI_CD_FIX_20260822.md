# Sửa lỗi CI/CD không chạy trên `Linh-dev-1`

## Nguyên nhân

Workflow `.github/workflows/ci.yml` trước đây chỉ có trigger push cho `main`, `master`, `develop` và pull request vào `main`, `master`. Nhánh phát triển hiện tại là `Linh-dev-1`, nên mỗi lần push lên nhánh này GitHub Actions không tạo run nào. Lịch sử GitHub chỉ có một run thành công trên nhánh `Linh-CI/CD`, không phải `Linh-dev-1`.

## Thay đổi

Workflow hiện đã chạy khi:

| Sự kiện | Branch |
|---|---|
| Push | `main`, `master`, `develop`, `Linh-dev-1` |
| Pull request | `main`, `master`, `develop`, `Linh-dev-1` |
| Chạy thủ công | `workflow_dispatch` |

Workflow cũng khai báo `permissions: contents: read` và dùng `npm ci` thay cho fallback `npm ci || npm install`, để lỗi dependency không bị che giấu.

## Các job hiện có

CI chạy song song build/test backend .NET 8 và build frontend Next.js. Backend restore, build Release và test `CloudService.Tests`; frontend cài dependency bằng `npm ci` rồi chạy `npm run build`.

## Giới hạn còn lại

Workflow hiện chưa có job build Docker image/push registry và chưa tạo coverage artifact. Đây là các hạng mục riêng cần bổ sung nếu yêu cầu chấm bắt buộc CI/CD đầy đủ hoặc triển khai container.
